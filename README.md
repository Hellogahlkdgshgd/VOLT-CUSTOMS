# VOLT-CUSTOMS

## Preview

Open `index.html` directly in a browser, or use the VS Code Live Server extension and choose **Open with Live Server**. The page has no build step or external dependencies.

The color selector updates a standalone sample. To connect it to an existing bike configurator, add color inputs with the IDs `seatColor`, `gripColor`, `plasticColor`, `wheelColor`, and `graphicsColor`; selected hex colors are sent through their `input` events. Fenders share `plasticColor`.
