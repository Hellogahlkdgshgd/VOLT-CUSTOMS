# VOLT-CUSTOMS

## Preview

Open `index.html` directly in a browser, or use the VS Code Live Server extension and choose **Open with Live Server**. No build step is required. The page loads Google's `<model-viewer>` library from its CDN and the hero photo from Wikimedia Commons, so an internet connection is needed for those assets.

The customizer accepts a local `.glb` or `.gltf` bike model. Choose a material for each part before changing its color. The build form downloads the request as a text file; it does not submit customer details to a server.
